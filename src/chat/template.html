三步就能开始聊天

这个页面不内置任何账号，用的是你自己的 DeepSeek API Key。Key 只存在这台设备上。

  1. 1. 去 DeepSeek 开放平台拿 Key

    打开 platform.deepseek.com/api_keys，登录后在「API keys」里点创建，会得到一串 sk-…；Key 只显示一次，当场复制。

  2. 2. 先充一点余额

    回到 platform.deepseek.com/top_up 充值，按量计费，几块钱能用很久。余额为 0 时接口返回 402，页面会直接提示你。

  3. 3. 把 Key 填进来

    点右上角 ⚙（或左下角「设置 / API Key」），粘贴 Key，点「测试连接」，看到绿色提示就成功了，然后回到这里直接说话。

头像、背景、提示词（含破甲）都在设置里，随时能改；不折腾这些也能正常聊天。
